# Tiltfill

유튜브 영상을 돌리고, 검은 띠를 잘라 내 화면을 채우는 크롬 확장입니다.

## 기능

- **회전**: 영상을 90도씩 돌립니다. 눕혀서 올라온 세로 영상을 바로 세울 수 있습니다.
- **화면 채우기**: 위아래나 좌우의 검은 띠를 잘라 내고 재생기를 채웁니다. 영상 파일 안에 들어 있는 띠도 찾아서 자릅니다.
- **PIP**: 영상을 항상 위에 뜨는 작은 창으로 띄웁니다. 돌린 방향과 잘라 낸 띠가 그대로 적용됩니다.
- **창 채움**: 전체화면으로 가지 않고 재생기를 브라우저 창 가득 채웁니다.
- **프레임 넘기기**: 마우스 휠로 한 프레임씩 넘깁니다.

## 설치

크롬 웹 스토어에는 아직 올리지 않았습니다. 올라가기 전까지는 아래 순서로 직접 빌드해서 넣습니다.

Node.js 22.18 이상이 있어야 합니다. 빌드 스크립트가 TypeScript 파일을 Node.js 로 바로 읽기 때문입니다. `node --version` 으로 먼저 확인하세요.

1. 저장소를 받고 그 폴더로 들어갑니다.

   ```
   git clone https://github.com/Argoneon1810/Tiltfill.git
   cd Tiltfill
   ```

2. 빌드에 필요한 것을 받습니다.

   ```
   npm install
   ```

3. 빌드합니다. 끝나면 `dist` 폴더가 생깁니다.

   ```
   npm run build
   ```

4. 크롬 주소창에 `chrome://extensions` 를 넣어 확장 프로그램 페이지를 엽니다.
5. 그 페이지에서 개발자 모드를 켭니다.
6. 압축을 풀어 둔 확장 프로그램을 불러오는 단추를 눌러, 3번에서 생긴 `dist` 폴더를 고릅니다. 저장소 폴더가 아니라 그 안의 `dist` 입니다.
7. 이미 열려 있던 유튜브 탭은 새로고침합니다. 크롬은 확장을 설치하기 전부터 열려 있던 탭에는 확장을 붙여 주지 않습니다.

새 판으로 올릴 때는 `git pull` 로 받은 뒤 2번과 3번을 다시 하고, 확장 프로그램 페이지에서 Tiltfill 을 다시 불러온 다음 유튜브 탭을 새로고침합니다.

## 사용법

### 패널 열기

조작은 모두 재생기 안에 뜨는 패널에서 합니다. 전체화면에서는 크롬의 확장 팝업을 열 수 없어서 패널을 페이지 안에 두었고, 전체화면에서도 같은 패널을 씁니다.

1. 유튜브에서 영상을 엽니다.
2. 재생기 오른쪽 위에 생긴 작은 단추를 누릅니다. 단축키는 `Ctrl+Alt+Shift+1` 입니다. 이 단추는 마우스를 가만히 두면 유튜브의 조작줄과 함께 사라지고, 마우스를 움직이면 다시 나옵니다.
3. 패널이 펼쳐집니다. 접을 때는 패널 오른쪽 위의 × 를 누르거나 같은 단축키를 다시 누릅니다.

오른쪽 위의 단추가 거슬리면 재생기 아래 유튜브 조작줄의 오른쪽 단추들 사이에 추가된 Tiltfill 단추를 누르세요. 조작판 전체가 감춰지고, 다시 누르면 돌아옵니다. 단축키는 `Ctrl+Alt+Shift+2` 입니다.

브라우저 도구 모음의 Tiltfill 아이콘을 누르면 나오는 팝업에는 조작 단추가 없습니다. 지금 상태 한 줄과 단축키 목록을 보여 주고, **재생기에서 패널 열기** 단추로 패널을 대신 열어 줍니다.

### 화면 채우기

패널 맨 위의 단추 네 개로 채움 방식을 고릅니다.

| 단추 | 하는 일 |
| --- | --- |
| **원래 크기** | 아무것도 하지 않습니다. |
| **상하 채움** | 그림의 높이를 재생기의 높이에 맞춥니다. 위아래 띠가 없어지고, 넘치는 좌우가 잘립니다. |
| **좌우 채움** | 그림의 폭을 재생기의 폭에 맞춥니다. 좌우 띠가 없어지고, 넘치는 위아래가 잘립니다. |
| **꽉 채움** | 위 둘 가운데 더 크게 키우는 쪽을 씁니다. 빈 곳이 남지 않습니다. |

단추 아래에는 지금 몇 배로 키웠고 어디가 얼마나 잘리는지가 `1.34배 · 좌우 26% 잘림` 같은 한 줄로 나옵니다.

### 영상 안에 들어 있는 검은 띠

채움을 골랐는데 아무 변화가 없다면, 띠가 영상 파일 안에 그림의 일부로 들어 있는 경우입니다. 유튜브가 보기에는 영상이 이미 재생기를 채우고 있어서 더 키울 것이 없습니다. 이때는 띠를 뺀 실제 그림의 비율을 알려 줘야 합니다.

- 영상을 재생해 둔 채로 **그림 비율** 줄의 **감지**를 누릅니다. 1~2초 동안 화면을 여러 번 읽어 띠를 찾고, 찾은 비율을 그림 비율에 넣습니다.
- 비율을 알고 있다면 **그림 비율** 목록에서 직접 고릅니다. `2.39 : 1` 부터 `9 : 16` 까지 흔한 비율이 들어 있습니다. **자동**은 영상이 알려 주는 비율을 그대로 쓴다는 뜻입니다.

### 잘리는 부분 고르기

화면을 채우면 어느 쪽인가는 잘려 나갑니다. 잘리는 부분이 생기면 패널에 **보이는 영역**이 나타납니다. 영상의 작은 사본 위에 지금 화면에 나오는 부분이 밝은 상자로 표시되고, 잘리는 부분은 어둡게 깔립니다.

- 밝은 상자를 끌어 옮기면 화면에 나오는 부분이 따라 바뀝니다. 상자 바깥을 누르면 상자가 그 자리로 옵니다.
- 두 번 누르거나 **가운데**를 누르면 가운데로 돌아갑니다.
- 미리보기에 초점이 있을 때는 방향키로도 옮길 수 있습니다. `Shift` 를 함께 누르면 크게 움직입니다.
- **그림**을 끄면 영상 그림을 그리지 않고 상자만 남습니다. 조작은 똑같이 됩니다.

### 돌리기

채움 단추 아래의 네 단추가 회전입니다. **바로**, **오른쪽 90도**(↻ 90), **180도**, **왼쪽 90도**(↺ 90) 가운데 하나를 고릅니다.

채움 방식이 **원래 크기**인 채로 90도를 돌리면, 돌린 그림이 재생기 안에 다 들어오도록 줄여서 보여 줍니다. 가로 화면에서 세로 영상을 온전히 보는 상태라 좌우에 검은 여백이 남습니다. 그 여백까지 채우려면 채움 방식을 함께 고르세요. 채움은 돌린 뒤의 모양을 기준으로 계산합니다.

### 창 채움

**창 채움**은 전체화면이 아닐 때 재생기를 브라우저 창 안쪽 가득 깔고, 페이지의 나머지를 감춥니다. 다시 누르면 풀립니다. 영상 페이지(주소가 `/watch` 인 페이지)에서만 걸리고, 켜 둔 상태는 다음 영상과 다음 방문에도 이어집니다.

### PIP

**PIP** 단추나 `Alt+P` 는 영상을 항상 위에 뜨는 작은 창으로 옮깁니다. 크롬의 기본 PIP 와 달리 돌려 놓은 방향 그대로 뜨고, 영상 안에 들어 있는 띠는 잘라 낸 채로 그림 전체를 보여 줍니다. 창이 떠 있는 동안 탭의 재생기는 화면이 비고, 창을 닫으면 영상이 제자리로 돌아옵니다.

작은 창 안에서 할 수 있는 일은 이렇습니다.

- 창을 누르면 재생과 정지가 바뀝니다. `Space` 와 `K` 도 같습니다. 좌우 방향키는 5초씩 건너뜁니다.
- 마우스를 올리면 위쪽에 조작줄이 나타납니다. 회전 단추 네 개와 그림 비율, 감지가 들어 있습니다. 회전을 바꾸면 창이 새 방향에 맞춰집니다.
- 유튜브 재생기에서 자막을 켜 두었으면 창에도 자막이 나옵니다. 영상을 돌려도 자막은 돌지 않습니다.
- 아래의 단축키와 프레임 넘기기가 이 창에서도 듣습니다.

### 한 프레임씩 넘기기

재생기나 PIP 창 위에서 휠을 가로로 굴리면 영상이 멈추고 한 프레임씩 넘어갑니다. 가로 휠이 없는 마우스는 `Shift` 를 누른 채 굴립니다. 처음에는 왼쪽(`Shift` 로는 위)으로 굴리는 쪽이 앞으로 가는 쪽입니다.

- 방향이 반대로 느껴지면 패널의 **휠 반대**를 누릅니다.
- 한 번에 여러 프레임씩 넘기려면 **휠 한 칸**에 숫자를 적습니다. 1부터 600까지 넣을 수 있습니다.

### 기억하는 것과 기억하지 않는 것

채움 방식, 창 채움, 휠 반대, 휠 한 칸, 그림 단추, 조작판을 감췄는지는 기억했다가 다음에도 그대로 씁니다.

그림 비율, 회전, 보이는 영역은 그 영상에만 맞는 값이라 다른 영상으로 넘어가면 처음으로 되돌립니다. 되돌릴 때는 화면에 "새 영상이라 그림 비율과 회전을 처음으로 되돌렸습니다"라고 알려 줍니다. 중간에 광고가 끼는 것으로는 되돌리지 않습니다.

## 단축키

유튜브 탭이나 PIP 창에 초점이 있을 때 듣는 키입니다. 검색창이나 댓글 칸에 글을 쓰는 중에는 듣지 않습니다.

| 키 | 하는 일 |
| --- | --- |
| `Ctrl+Alt+Shift+1` | 패널 펼치기 / 접기 |
| `Ctrl+Alt+Shift+2` | 조작판 띄우기 / 감추기 |
| `Ctrl+Alt+Shift+3` | 채움 방식 바꾸기. 원래 크기 → 상하 채움 → 좌우 채움 → 꽉 채움 순서로 돕니다. |
| `Ctrl+Alt+Shift+4` | 회전 바꾸기. 바로 → 오른쪽 90도 → 180도 → 왼쪽 90도 순서로 돕니다. |
| `Ctrl+Alt+Shift+5` | 되돌리기. 채움 방식을 원래 크기로, 회전을 바로, 보이는 영역을 가운데로 돌리고 창 채움을 풉니다. 그림 비율은 그대로 둡니다. |
| `Ctrl+Alt+Shift+6` | 창 가득 채우기 켜기 / 끄기 |
| `Alt+P` | PIP 열기 / 닫기 |

세 키를 한꺼번에 누르게 한 것은 글을 쓰거나 다른 일을 하다가 실수로 누르는 일이 없게 하려는 것입니다. 숫자는 글자판 위쪽의 숫자열이고, 자판의 자리로 알아보기 때문에 한글 입력 상태에서도 그대로 듣습니다.

아래 두 키는 크롬에 등록되는 브라우저 단축키라서 페이지에 초점이 없을 때도 듣습니다. 크롬이 이쪽에는 `Ctrl+Alt` 조합을 받아 주지 않아 키가 다릅니다. 적힌 키는 처음 제안되는 값이고, `chrome://extensions/shortcuts` 에서 바꿀 수 있습니다.

| 키 | 하는 일 |
| --- | --- |
| `Alt+Shift+8` | 채움 방식 바꾸기 |
| `Alt+Shift+9` | 원래 크기로 되돌리기 |

## 안 되는 것과 알아 둘 점

- **다른 사이트에 끼워 넣은 유튜브 영상에서는 동작하지 않습니다.** 주소가 `youtube.com` 인 페이지에만 붙습니다.
- **네 변에 모두 띠가 있는 영상은 아직 제대로 채우지 못합니다.** 그림 비율은 그림의 모양만 말하고 크기는 말하지 못해서, 그림이 가로와 세로 어느 쪽에도 닿지 않는 영상에서는 띠가 남습니다. 고칠 계획은 [BACKLOG.md](BACKLOG.md) 에 있습니다.
- **감지는 재생 중인 화면을 읽습니다.** 화면이 계속 검은 장면에서는 찾지 못하니 밝은 장면에서 다시 누르세요. 그림이 가로나 세로의 30% 도 안 되게 잡히면 잘못 잡은 것으로 보고 적용하지 않습니다.
- **PIP 창의 테두리를 끌어 크기를 바꾸면 여백이 생길 수 있습니다.** 이 창은 크롬의 기본 PIP 창과 달리 끄는 동안 비율이 잠기지 않습니다. 창 안을 한 번 누르면 그림에 맞게 다시 맞춰지고, 그 누름으로는 재생이 멈추지 않습니다.
- **돌린 방향 그대로 뜨는 PIP 는 크롬 116 이상에서 됩니다.** 그보다 낮은 크롬에서는 기본 PIP 로 열리고 회전이 반영되지 않습니다.
- **PIP 는 유튜브 탭에서 키를 누르거나 패널의 단추를 눌러야 열립니다.** 창을 여는 일은 크롬이 사용자의 직접 조작을 요구하기 때문입니다. 도구 모음 팝업에는 PIP 단추가 없습니다.
- **프레임 넘기기는 재생을 한 번 한 뒤에 정확합니다.** 브라우저가 영상의 프레임 수를 알려 주지 않아서, 재생 중에 한 프레임의 길이를 직접 잽니다. 한 번도 재생하지 않은 영상에서는 초당 30프레임으로 치고 넘깁니다.
- **같은 일을 하는 다른 확장과 함께 켜면 부딪힙니다.** 창 채움은 같은 기능을 가진 확장과 재생기를 두고 다투고, `Alt+P` 는 구글의 PIP 확장이 쓰는 키와 같습니다.
- **보호된 영상은 보이는 영역의 미리보기 그림이 나오지 않습니다.** "이 영상은 그림을 읽을 수 없습니다"라고 나오고, 상자를 끌어 옮기는 조작은 그대로 됩니다.
- **팝업에 "확장이 이 탭에는 아직 붙지 않았습니다"가 나오면** 설치나 업데이트 전부터 열려 있던 탭입니다. 팝업의 **이 탭 새로고침**을 누르세요.
- **화면의 글은 한국어와 영어 두 가지입니다.** 크롬의 언어가 한국어면 한국어로, 그 밖에는 영어로 나옵니다.

## 권한과 개인정보

요구하는 권한은 두 가지입니다. 설정을 저장하는 `storage` 와 유튜브 페이지에 대한 접근입니다. 설정은 브라우저 안에만 저장하고, 소스에는 바깥으로 무언가를 보내는 코드가 없습니다.

## 고쳐 쓰려는 분께

소스는 TypeScript 이고 `src/` 에 있습니다. 크롬에 불러오는 것은 언제나 빌드 결과인 `dist/` 입니다.

| 명령 | 하는 일 |
| --- | --- |
| `npm run build` | 타입을 검사하고 한 번 빌드합니다. |
| `npm run watch` | 파일을 고칠 때마다 다시 빌드합니다. 타입 검사는 하지 않습니다. |
| `npm run typecheck` | 타입 검사만 합니다. |

빌드한 뒤에는 크롬의 확장 프로그램 페이지에서 Tiltfill 을 다시 불러오고 유튜브 탭을 새로고침해야 바뀐 것이 보입니다.

어디에 무엇이 있는지는 이렇습니다.

| 파일 | 맡은 일 |
| --- | --- |
| `src/core.ts` | 배율 계산, 채움과 회전 적용, 검은 띠 감지 |
| `src/ui.ts` | 재생기 안의 패널과 단추, 키 처리 |
| `src/pip.ts` | PIP 창 |
| `src/winfill.ts` | 창 가득 채우기 |
| `src/frames.ts` | 프레임 넘기기 |
| `src/shortcuts.ts` | 모든 단축키. 키는 여기에만 적습니다. |
| `src/popup.ts` | 도구 모음 팝업 |
| `src/background.ts` | 브라우저 단축키를 탭으로 넘기는 서비스 워커 |
| `static/_locales/` | 화면의 글. `ko` 와 `en` 두 벌입니다. |
| `static/manifest.json` | 권한과 버전. 버전 번호는 여기에만 적습니다. |

고치기 전에 알아 두면 좋은 것이 두 가지 있습니다.

- 단축키를 바꾸려면 `src/shortcuts.ts` 만 고칩니다. 화면의 안내 글과 `manifest.json` 의 `commands` 는 빌드가 그 표에서 만듭니다.
- 화면에 나오는 글을 더하거나 빼면 `ko` 와 `en` 의 `messages.json` 을 함께 고칩니다. 한쪽에만 있는 열쇠나 쓰이지 않는 열쇠가 있으면 빌드가 멈춥니다.

판마다 무엇을 왜 바꿨는지는 [CHANGELOG.md](CHANGELOG.md) 에 있습니다. 유튜브 재생기와 크롬의 동작 때문에 생긴 문제와 그 원인을 함께 적어 두었으니, 이상한 증상을 만나면 먼저 거기서 찾아보세요.

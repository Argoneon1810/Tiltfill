# Tiltfill

**한국어** | [English](README.en.md)

유튜브 영상을 돌리고, 검은 띠를 잘라 내 화면을 채우는 크롬 확장입니다.

## 기능

- **회전**: 영상을 90도씩 돌립니다. 눕혀서 올라온 세로 영상을 바로 세울 수 있습니다.
- **화면 채우기**: 위아래나 좌우의 검은 띠를 잘라 내고 재생기를 채웁니다. 영상 파일 안에 들어 있는 띠도 찾아서 자릅니다.
- **PIP**: 영상을 항상 위에 뜨는 작은 창으로 띄웁니다. 돌린 방향과 잘라 낸 띠가 그대로 적용됩니다.
- **창 채움**: 전체화면으로 가지 않고 재생기를 브라우저 창 가득 채웁니다.
- **휠로 넘기기**: 마우스 휠로 영상을 5초씩, 10초씩, 또는 한 프레임씩 넘깁니다.

## 설치

[크롬 웹 스토어의 Tiltfill 페이지](https://chromewebstore.google.com/detail/tiltfill/ekodgikandbohjbgfofemohoefkpgkpd)에서 **Chrome에 추가**를 누릅니다. 설치한 뒤에는 열려 있던 유튜브 탭을 새로고침합니다.

### 소스에서 직접 빌드하기

코드를 고쳐 쓰거나 스토어에 올라가기 전의 판을 써 보려면 직접 빌드해서 넣습니다. Node.js 22.18 이상이 필요합니다.

1. 저장소를 받아 빌드합니다. 끝나면 `dist` 폴더가 생깁니다.

   ```
   git clone https://github.com/Argoneon1810/Tiltfill.git
   cd Tiltfill
   npm install
   npm run build
   ```

2. 크롬에서 `chrome://extensions` 를 열고 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `dist` 폴더를 고릅니다. 저장소 폴더가 아니라 그 안의 `dist` 입니다.
4. 열려 있던 유튜브 탭을 새로고침합니다. 확장을 넣기 전에 열린 탭에는 확장이 붙지 않습니다.

새 판을 받을 때는 `git pull` 과 `npm run build` 를 다시 하고, `chrome://extensions` 에서 Tiltfill 을 새로고침한 뒤 유튜브 탭도 새로고침합니다.

## 사용법

### 패널 열기

유튜브에서 영상을 열면 재생기 오른쪽 위에 작은 단추가 생깁니다. 이 단추를 누르면 패널이 펼쳐지고, 아래의 조작은 모두 이 패널에서 합니다. 전체화면에서도 똑같이 뜹니다.

단추는 유튜브의 조작줄이 사라질 때 함께 사라집니다. 마우스를 움직이면 다시 나옵니다.

이 단추조차 보고 싶지 않으면 유튜브 조작줄 오른쪽에 추가된 Tiltfill 단추를 누릅니다. 단추와 패널이 통째로 감춰지고, 다시 누르면 돌아옵니다.

### 화면 채우기

패널 맨 위의 단추 네 개에서 고릅니다.

| 단추 | 하는 일 |
| --- | --- |
| **원래 크기** | 아무것도 하지 않습니다. |
| **상하 채움** | 그림의 높이를 재생기에 맞춥니다. 위아래 띠가 없어지고 좌우가 잘립니다. |
| **좌우 채움** | 그림의 폭을 재생기에 맞춥니다. 좌우 띠가 없어지고 위아래가 잘립니다. |
| **꽉 채움** | 어느 쪽에도 띠가 남지 않을 만큼 키웁니다. |

단추 아래에 몇 배로 키웠고 어디가 얼마나 잘리는지가 `1.34배 · 좌우 26% 잘림` 처럼 나옵니다.

**채움을 골랐는데 아무 변화가 없으면** 띠가 영상 파일 안에 그림의 일부로 들어 있는 것입니다. 영상을 재생해 둔 채로 **그림 비율** 옆의 **감지**를 누르면 화면을 1~2초 읽어 띠를 찾아냅니다. 감지가 틀렸거나 비율을 이미 알고 있으면 **그림 비율** 목록에서 직접 고릅니다.

### 잘리는 부분 고르기

화면을 채우면 그림의 일부가 잘립니다. 그때 패널에 영상의 작은 미리보기가 나타나고, 지금 화면에 나오는 부분이 밝은 상자로 표시됩니다.

- 상자를 끌면 화면에 나오는 부분이 따라 움직입니다. 상자 바깥을 누르면 상자가 그리로 옵니다.
- 두 번 누르거나 **가운데**를 누르면 가운데로 돌아갑니다.
- 미리보기를 누른 뒤에는 방향키로도 옮길 수 있습니다. `Shift` 를 함께 누르면 크게 움직입니다.
- 미리보기가 컴퓨터에 부담이 되면 **그림**을 끕니다. 영상 그림은 사라지고 상자만 남으며, 조작은 똑같이 됩니다.

### 돌리기

채움 단추 아래의 네 단추에서 방향을 고릅니다. 바로, 오른쪽 90도, 180도, 왼쪽 90도입니다.

채움 없이 90도만 돌리면 그림 전체가 보이도록 줄어들어 좌우에 여백이 남습니다. 그 여백까지 채우려면 채움 방식을 함께 고릅니다.

### PIP

패널의 **PIP** 나 `Alt+P` 를 누르면 영상이 항상 위에 뜨는 작은 창으로 옮겨 갑니다. 창을 닫거나 같은 키를 다시 누르면 제자리로 돌아옵니다. 창이 떠 있는 동안 탭의 재생기는 화면이 비어 있습니다.

- 돌려 놓은 방향과 잘라 낸 띠가 창에도 그대로 적용됩니다. 크롬에 원래 있는 PIP 는 돌린 영상을 다시 눕혀서 보여 줍니다.
- 창을 누르면 재생과 정지가 바뀝니다. `Space` 도 같고, 좌우 방향키는 5초씩 건너뜁니다.
- 창에 마우스를 올리면 위쪽에 회전과 그림 비율을 바꾸는 조작줄이 나타납니다.
- 유튜브에서 자막을 켜 두었으면 창에도 자막이 나옵니다.
- 단축키와 휠로 넘기기가 이 창에서도 듣습니다.

### 창 채움

패널의 **창 채움**을 누르면 재생기가 브라우저 창 안쪽을 가득 채우고, 제목과 댓글 같은 페이지의 나머지는 보이지 않게 됩니다. 다시 누르면 풀립니다. 켜 둔 상태는 다음 영상에서도 이어집니다.

### 휠로 넘기기

재생기나 PIP 창 위에서 휠을 가로로 굴리면 영상이 앞뒤로 넘어갑니다. 가로 휠이 없는 마우스는 `Shift` 를 누른 채 굴립니다.

| 굴리는 방법 | 한 칸에 넘어가는 양 |
| --- | --- |
| 그냥 굴림 | 5초 |
| `Alt` 를 누른 채 | 한 프레임. 영상이 멈춥니다. |
| `Ctrl` 을 누른 채 | 10초 |

- 방향이 반대로 느껴지면 패널의 **휠 반대**를 누릅니다.
- `Alt` 로 한 번에 여러 프레임씩 넘기려면 패널의 **작은 점프**에 프레임 수를 적습니다.

### 기억하는 것과 잊는 것

채움 방식, 창 채움, 휠 설정처럼 취향에 가까운 것은 기억해서 다음에도 그대로 씁니다.

그림 비율, 회전, 잘리는 부분의 위치는 그 영상에만 맞는 값이라, 다른 영상으로 넘어가면 처음으로 돌아갑니다.

## 단축키

유튜브 탭이나 PIP 창에서 듣습니다. 검색창이나 댓글에 글을 쓰는 중에는 듣지 않습니다.

| 키 | 하는 일 |
| --- | --- |
| `Ctrl+Alt+Shift+1` | 패널 펼치기 / 접기 |
| `Ctrl+Alt+Shift+2` | 단추와 패널을 통째로 띄우기 / 감추기 |
| `Ctrl+Alt+Shift+3` | 채움 방식을 차례로 바꾸기 |
| `Ctrl+Alt+Shift+4` | 회전을 차례로 바꾸기 |
| `Ctrl+Alt+Shift+5` | 채움, 회전, 창 채움을 모두 되돌리기 |
| `Ctrl+Alt+Shift+6` | 창 채움 켜기 / 끄기 |
| `Alt+P` | PIP 열기 / 닫기 |

숫자는 글자판 위쪽의 숫자열입니다. 키를 세 개씩 함께 누르게 한 것은 글을 쓰다가 실수로 눌리지 않게 하려는 것입니다.

아래 둘은 유튜브 탭을 보고 있지 않을 때도 듣습니다. `chrome://extensions/shortcuts` 에서 다른 키로 바꿀 수 있습니다.

| 키 | 하는 일 |
| --- | --- |
| `Alt+Shift+8` | 채움 방식을 차례로 바꾸기 |
| `Alt+Shift+9` | 모두 되돌리기 |

## 알아 둘 점

- **`www.youtube.com` 에서만 됩니다.** 다른 사이트에 끼워 넣은 유튜브 영상, 유튜브 뮤직에서는 동작하지 않습니다.
- **네 변 모두에 띠가 있는 영상은 아직 다 채우지 못합니다.** 띠가 일부 남습니다. [BACKLOG.md](BACKLOG.md) 에 고칠 계획이 있습니다.
- **감지는 어두운 장면에서 실패할 수 있습니다.** 밝은 장면에서 다시 누릅니다.
- **보호된 영상에서는 감지와 미리보기 그림이 나오지 않습니다.** 유튜브 영화 같은 영상입니다. 그림 비율을 직접 고르면 나머지는 똑같이 됩니다.
- **PIP 창은 테두리를 끌 때 영상의 비율이 저절로 유지되지 않습니다.** 여백이 생겼으면 창 안을 한 번 누르면 그림에 맞춰집니다.
- **돌린 방향이 유지되는 PIP 는 크롬 116 이상에서 됩니다.** 그보다 낮으면 크롬의 기본 PIP 로 열립니다.
- **프레임 단위로 넘기는 것은 영상을 잠깐이라도 재생한 뒤에 정확합니다.** 한 번도 재생하지 않은 영상은 초당 30프레임인 것으로 치고 넘깁니다.
- **같은 일을 하는 확장과 함께 켜면 부딪힙니다.** 구글의 Picture-in-Picture 확장도 `Alt+P` 를 쓰고, 재생기를 창에 채워 주는 다른 확장은 창 채움과 충돌합니다. 한쪽만 켭니다.
- **확장 아이콘을 눌렀을 때 "확장이 이 탭에는 아직 붙지 않았습니다"가 나오면** 그 탭을 새로고침합니다.
- **화면의 글은 한국어와 영어입니다.** 크롬의 언어가 한국어면 한국어로, 그 밖에는 영어로 나옵니다.

## 권한과 개인정보

아무것도 모으지 않고 어디로도 보내지 않습니다. 소스에 바깥으로 무언가를 보내는 코드가 없습니다.

요구하는 권한은 유튜브 페이지에 대한 접근과, 설정을 저장하는 `storage` 둘입니다. 감지와 미리보기를 위해 영상 화면을 읽지만 그 일은 브라우저 안에서 끝나고, 설정도 브라우저 안에만 저장합니다.

## 고쳐 쓰려는 분께

소스는 TypeScript 이고 `src/` 에 있습니다. 크롬에 불러오는 것은 빌드 결과인 `dist/` 입니다.

| 명령 | 하는 일 |
| --- | --- |
| `npm run build` | 타입을 검사하고 한 번 빌드합니다. |
| `npm run watch` | 파일을 고칠 때마다 다시 빌드합니다. 타입 검사는 하지 않습니다. |
| `npm run typecheck` | 타입 검사만 합니다. |
| `npm run package` | 새로 빌드한 뒤 스토어에 올릴 zip 을 `release/` 에 만듭니다. |

빌드한 뒤에는 `chrome://extensions` 에서 Tiltfill 을 새로고침하고 유튜브 탭도 새로고침해야 바뀐 것이 보입니다.

| 파일 | 맡은 일 |
| --- | --- |
| `src/core.ts` | 배율 계산, 채움과 회전 적용, 검은 띠 감지 |
| `src/ui.ts` | 재생기 안의 패널과 단추, 키 처리 |
| `src/pip.ts` | PIP 창 |
| `src/winfill.ts` | 창 채움 |
| `src/frames.ts` | 휠로 넘기기 |
| `src/shortcuts.ts` | 모든 단축키와 휠 걸음의 크기 |
| `src/popup.ts` | 확장 아이콘을 눌렀을 때 뜨는 창 |
| `src/background.ts` | 브라우저 단축키를 탭으로 넘기는 서비스 워커 |
| `static/_locales/` | 화면의 글. `ko` 와 `en` 두 벌입니다. |
| `static/manifest.json` | 권한과 버전 |

- 단축키를 바꾸려면 `src/shortcuts.ts` 만 고칩니다. 화면의 안내 글과 `manifest.json` 의 `commands` 는 빌드가 거기서 만듭니다.
- 화면의 글을 더하거나 빼면 `ko` 와 `en` 의 `messages.json` 을 함께 고칩니다. 한쪽에만 있는 열쇠가 있으면 빌드가 멈춥니다.

판마다 무엇을 왜 바꿨는지는 [CHANGELOG.md](CHANGELOG.md) 에 있습니다. 유튜브 재생기와 크롬의 동작 때문에 생긴 문제와 그 원인을 적어 두었으니, 이상한 증상을 만나면 먼저 거기서 찾아보세요.

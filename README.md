# Tiltfill

유튜브 영상을 돌리고, 검은 여백을 잘라 화면을 채우는 크롬 확장입니다.

이런 때 씁니다.

- **세로로 찍은 영상이 눕혀져 올라와 있을 때.** 영상을 돌려서 바로 세웁니다. 작은 창(PIP)으로
  띄워도 돌린 방향이 그대로입니다.
- **영상 위아래나 양옆에 검은 띠가 남을 때.** 띠를 잘라 내고 그림을 재생기에 가득 채웁니다.
  영상 파일 안에 이미 들어 있는 띠도 찾아서 자릅니다.
- **전체화면은 부담스럽고 브라우저 창만큼은 크게 보고 싶을 때.** 재생기를 창 가득 채웁니다.
- **한 장면을 한 프레임씩 넘겨 보고 싶을 때.** 마우스 휠로 넘깁니다.

`youtube.com` 에서만 동작합니다. 화면의 글은 크롬의 언어가 한국어면 한국어로, 그 밖에는
영어로 나옵니다.

## 설치

아직 크롬 웹 스토어에 올라가 있지 않습니다. 지금은 소스를 받아 직접 만들어 넣어야 합니다.
[Node.js](https://nodejs.org) 22.18 이상이 깔려 있어야 합니다.

1. 저장소를 받아 확장을 만듭니다.

   ```
   git clone https://github.com/Argoneon1810/Tiltfill.git
   cd Tiltfill
   npm install
   npm run build
   ```

2. 크롬에서 `chrome://extensions` 를 열고 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고, 방금 생긴 `dist` 폴더를 고릅니다.
   저장소 폴더가 아니라 그 안의 `dist` 입니다.
4. 이미 열려 있던 유튜브 탭은 새로고침합니다. 크롬은 확장을 넣기 전에 열린 탭에는 확장을
   붙여 주지 않습니다.

## 쓰는 법

### 패널 열기

유튜브 영상 페이지에서 재생기 오른쪽 위에 작은 단추가 생깁니다. 그 단추를 누르면 패널이
펼쳐집니다. 아래의 조작은 모두 이 패널에서 합니다. 전체화면에서도 같은 자리에 같은 패널이
뜹니다.

- 단추는 재생기의 조작줄이 사라질 때 함께 사라집니다. 마우스를 움직이면 다시 나타납니다.
- 채움이나 회전이 걸려 있으면 단추가 파랗게 바뀝니다.
- 단추 자체가 거슬리면 재생기 조작줄에 있는 Tiltfill 버튼으로 통째로 감출 수 있습니다.
- 브라우저 도구 모음의 확장 아이콘을 누르면 지금 상태와 단축키 목록이 나옵니다.

### 검은 띠 없애기

패널 맨 위의 단추 넷 가운데 하나를 고릅니다.

| 방식 | 하는 일 |
| --- | --- |
| 원래 크기 | 아무것도 하지 않습니다. |
| 상하 채움 | 그림의 높이를 재생기 높이에 맞춥니다. 위아래 띠가 사라지고 좌우가 잘립니다. |
| 좌우 채움 | 그림의 폭을 재생기 폭에 맞춥니다. 좌우 띠가 사라지고 위아래가 잘립니다. |
| 꽉 채움 | 어느 쪽에도 띠가 남지 않을 만큼 키웁니다. |

채우면 그림의 일부가 잘립니다. 잘리는 부분이 있을 때는 패널에 영상의 작은 미리보기가
나타나고, 지금 화면에 나오는 부분이 밝은 상자로 표시됩니다. 그 상자를 끌어 어디를 볼지
고릅니다. 두 번 누르면 가운데로 돌아갑니다.

**채움을 골랐는데 아무 일도 일어나지 않는다면** 띠가 영상 파일 안에 들어 있는 경우입니다.
16:9 영상 안에 더 넓은 영화 화면이 들어 있을 때가 그렇습니다. 영상을 재생해 둔 채로
**감지**를 누르면 2초쯤 화면을 읽어 띠를 찾고, 그 띠를 뺀 그림을 기준으로 다시 채웁니다.
감지가 틀렸으면 **그림 비율**에서 직접 고릅니다.

### 돌리기

패널의 둘째 줄에서 방향을 고릅니다. 바로, 오른쪽 90도, 180도, 왼쪽 90도가 있습니다.
돌리기만 하고 채움을 고르지 않으면 돌린 그림이 재생기 안에 다 들어오도록 줄입니다.

### 작은 창으로 띄우기 (PIP)

`Alt+P` 를 누르거나 패널의 **PIP** 를 누르면 영상이 항상 위에 뜨는 작은 창으로 옮겨 갑니다.
같은 키를 다시 누르거나 창을 닫으면 원래 자리로 돌아옵니다.

- 돌려 둔 방향과 잘라 둔 띠가 작은 창에도 그대로 적용됩니다. 창이 떠 있는 동안 돌리면
  창이 새 방향에 맞춰집니다.
- 유튜브에서 자막을 켜 두었으면 작은 창에도 자막이 나옵니다.
- 창 안을 누르면 재생과 정지가 바뀝니다. 창에 마우스를 올리면 위쪽에 회전과 그림 비율을
  바꾸는 조작줄이 나타납니다.
- 창이 떠 있는 동안 유튜브 탭의 재생기는 화면이 비어 있습니다. 영상이 창으로 옮겨 가 있는
  동안의 정상 동작입니다.

### 창 가득 채우기

패널의 **창 채움**이나 `Ctrl+Alt+Shift+6` 을 누르면 재생기가 브라우저 창 안쪽을 가득 채웁니다.
제목, 댓글, 추천 목록은 그동안 보이지 않습니다. 같은 단추나 키로 끕니다. 켜 둔 상태는
기억해서 다음 영상에서도 이어집니다.

### 한 프레임씩 넘기기

재생기 위에서 마우스 휠을 가로로 굴리면 영상이 멈추고 한 프레임씩 넘어갑니다. 가로 휠이
없는 마우스는 `Shift` 를 누른 채 굴립니다. 작은 창(PIP) 위에서도 됩니다.

- 굴리는 방향이 반대로 느껴지면 패널의 **휠 반대**를 누릅니다.
- 한 번에 여러 프레임씩 넘기려면 패널의 **휠 한 칸**에 프레임 수를 적습니다.
- 영상을 잠깐이라도 재생한 뒤에 정확합니다. 한 번도 재생하지 않은 영상은 초당 30프레임인
  것으로 치고 넘깁니다.

### 단축키

| 키 | 하는 일 |
| --- | --- |
| `Ctrl+Alt+Shift+1` | 패널 펼치기 / 접기 |
| `Ctrl+Alt+Shift+2` | 재생기의 단추와 패널을 통째로 띄우기 / 감추기 |
| `Ctrl+Alt+Shift+3` | 채움 방식을 차례로 바꾸기 |
| `Ctrl+Alt+Shift+4` | 회전을 차례로 바꾸기 |
| `Ctrl+Alt+Shift+5` | 채움, 회전, 창 채움을 모두 되돌리기 |
| `Ctrl+Alt+Shift+6` | 창 가득 채우기 켜기 / 끄기 |
| `Alt+P` | 작은 창(PIP) 열기 / 닫기 |
| 가로 휠, 또는 `Shift` + 휠 | 한 프레임씩 넘기기 |
| 방향키 | 미리보기를 누른 뒤, 보이는 부분 옮기기 (`Shift` 와 함께면 크게) |
| `Alt+Shift+8` | 채움 방식을 차례로 바꾸기 |
| `Alt+Shift+9` | 모두 되돌리기 |

키가 세 개씩 붙은 것은 글을 쓰거나 다른 프로그램을 쓰다가 실수로 눌리지 않게 하려는
것입니다. 맨 아래 두 개는 유튜브 탭에 초점이 없어도 듣고, `chrome://extensions/shortcuts`
에서 다른 키로 바꿀 수 있습니다. 나머지는 유튜브 탭이나 작은 창에 초점이 있을 때 듣습니다.

## 알아 둘 점

- **기억하는 것과 잊는 것.** 채움 방식, 창 채움, 휠 설정은 기억합니다. 그림 비율, 회전, 보이는
  부분은 그 영상에만 맞는 값이라 다른 영상으로 넘어가면 처음으로 돌아갑니다.
- **유튜브 사이트에서만 됩니다.** 다른 사이트에 끼워 넣은 유튜브 영상에서는 동작하지 않습니다.
- **보호된 영상.** 유튜브 영화처럼 복제 방지가 걸린 영상은 화면을 읽을 수 없어서 감지와
  미리보기 그림이 나오지 않습니다. 그림 비율을 직접 고르면 나머지는 똑같이 됩니다.
- **작은 창의 모양.** 크롬에 원래 있는 PIP 창과 달리, 창 테두리를 끌 때 영상의 비율이 저절로
  유지되지 않습니다. 여백이 생겼으면 창 안을 한 번 누르면 그림에 맞춰집니다.
- **구글의 Picture-in-Picture 확장과 함께 쓸 때.** 두 확장이 `Alt+P` 를 같이 씁니다. 한쪽을
  끄거나 `chrome://extensions/shortcuts` 에서 그쪽의 키를 바꿉니다.
- **창 가득 채우기가 있는 다른 확장.** 같은 기능을 둘이 동시에 걸면 재생기가 어긋납니다.
  한쪽만 켭니다.

## 개인정보

아무것도 모으지 않고, 어디로도 보내지 않습니다. 이 확장은 인터넷에 접속하는 코드가
없습니다. 띠를 찾을 때와 미리보기를 그릴 때 영상 화면을 읽는데, 그 일은 브라우저 안에서
끝납니다. 저장하는 것은 위에 적은 설정 몇 가지뿐이고, 크롬의 확장 저장소에 들어갑니다.

## 고쳐 쓰려는 분께

```
npm run build      # 타입을 검사하고 dist/ 에 만든다
npm run watch      # 고칠 때마다 다시 만든다 (타입 검사는 하지 않는다)
```

만든 뒤에는 `chrome://extensions` 에서 확장을 새로고침하고 유튜브 탭도 새로고침해야 바뀐
코드가 돕니다.

원리는 단순합니다. `<video>` 요소에 CSS `transform` 으로 이동, 회전, 확대를 걸고, 넘치는
부분은 그 위 요소의 `overflow: hidden` 으로 잘라 냅니다. 유튜브가 재생기 크기를 바꾸거나
걸어 둔 값을 지우면 알아채고 다시 겁니다.

| 파일 | 맡은 일 |
| --- | --- |
| `src/core.ts` | 영상과 재생기 찾기, 배율 계산, `transform` 걸기, 띠 감지 |
| `src/ui.ts` | 재생기의 단추와 패널, 미리보기, 키와 휠 받기 |
| `src/pip.ts` | 작은 창(PIP)과 그 안의 자막, 조작줄 |
| `src/winfill.ts` | 창 가득 채우기 |
| `src/frames.ts` | 프레임 넘기기, 프레임 길이 재기 |
| `src/shortcuts.ts` | 모든 단축키. 키를 바꾸려면 여기만 고친다 |
| `src/popup.ts`, `static/popup.*` | 도구 모음의 확장 아이콘을 눌렀을 때 뜨는 창 |
| `src/background.ts` | 브라우저 단축키를 유튜브 탭으로 넘기기 |
| `static/_locales/{ko,en}/messages.json` | 화면의 글. 소스에서는 `t("열쇠")` 로 가져온다 |
| `scripts/build.mjs` | esbuild 로 묶기, 단축키와 글의 열쇠 확인 |

화면의 글을 더하거나 고칠 때는 한국어와 영어 두 파일을 함께 고칩니다. 한쪽에만 있는
열쇠가 있으면 빌드가 멈추고 무엇이 빠졌는지 알려 줍니다.

판마다 무엇이 왜 바뀌었는지는 [CHANGELOG.md](CHANGELOG.md) 에 있습니다. 유튜브 재생기와
크롬의 동작 때문에 생긴 문제와 그 원인을 적어 두었으므로, 코드의 어떤 부분이 왜 그렇게
되어 있는지 궁금할 때 먼저 찾아볼 곳입니다. 아직 하지 못한 일은 [BACKLOG.md](BACKLOG.md) 에
있습니다.

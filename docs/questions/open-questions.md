## Q3. 개인정보 보호 관행 탭을 어떻게 채울지

두 보고서의 판단이 다르다.

- 코드리뷰 I1: 외부로 전송하지 않으므로 수집하는 데이터 유형은 체크하지 않는다.
- 웹 조사 4.3.7: 기기 안에서만 처리해도 사용자 데이터를 "handle"하는 것에 해당할 수 있다. 이 확장은 캔버스로 영상 프레임을 읽는다.
- 어느 쪽이든 "수집·전송하지 않고, 프레임은 기기 안에서만 처리한다"는 짧은 개인정보처리방침 페이지를 두는 편이 안전하다. 이 페이지를 어디에 둘지도 정해야 한다.
- 출처: 코드리뷰 I1, 웹 조사 4.3 (2026-09-30)

## Q8. 스토어 등록 이미지를 어떻게 마련할지

아이콘과 달리 아직 하나도 없고, 없으면 반려된다(Yellow Zinc). 필수다.

- 스크린샷: 최소 1장, 최대 5장. 1280×800 권장, 640×400 허용. 모서리는 각지게, 여백 없이 꽉 채운다.
- 작은 프로모션 타일 440×280: 필수. 없으면 있는 확장보다 뒤에 노출된다.
- 마키 1400×560: 선택.
- 주의: 스크린샷에 다른 사람의 영상 저작물이 크게 담기지 않게 한다(웹 조사 4.4.7). 직접 찍은 영상이나 저작권 걱정 없는 영상으로 찍는다.
- 캡처용 영상 후보 (2026-09-30 조사): Blender Studio 오픈 무비는 대체로 CC-BY 이고 저작권자는 Blender Foundation 이다. 필름마다 라이선스 문구가 따로 붙으니 쓰기 전에 확인한다. Agent 327 은 CC-BY-ND 라 확대해 자른 "후" 화면이 변형물로 볼 여지가 있어 피한다. 제작 중인 작품(Cowboi, Overgrown)도 피한다. 정정 (2026-09-30 사용자 확인): Blender 공식 채널의 Sintel 업로드(watch?v=eRsGyueVLvQ)는 띠 없는 16:9 라 "1.00배 · 잘리는 부분 없음" 이 나온다. 적용 전후 시연에는 맞지 않는다. 띠가 구워진 업로드를 찾거나(Tears of Steel 등 확인 필요), 창 비율로 생기는 띠로 시연한다. 쓰면 설명 끝에 출처 표기를 넣는다. 출처: https://studio.blender.org/remixing/
- 19편 전체 저작권 조사 (2026-09-30): [blender-open-movie-licenses](../researchs/2026-09-30_1115_blender-open-movie-licenses.md). 추천은 Charge, Sprite Fright, Spring (모두 CC BY 4.0, 원작 약 2.39:1). 부적합: Agent 327(CC BY-ND), Cowboi·Overgrown(제작 중). 출처 표기는 "(CC) Blender Foundation | studio.blender.org" 에 변경했음을 밝히고, Blender 로고와 작품 제목 로고가 나오는 장면은 피한다. 유튜브 파일 안에 띠가 구워졌는지는 미확인이라 직접 틀어 봐야 한다.
- Charge 확인 (2026-09-30 사용자 스크린샷): 전체화면, 비율 "자동", 오른쪽 90° + 좌우 채움에서 2.39배가 나왔다. 16:9 파일이면 1.78배가 나와야 하므로, 이 업로드는 띠가 구워진 16:9 가 아니라 2.39:1 파일 그대로이고 띠는 재생기가 만든 것으로 보인다. 감지 없이 "자동" 만으로 상하 채움 시연이 된다. 이어서 회전 없이 원래 크기 1.00배(위아래 띠 보임) → 상하 채움 1.34배(좌우 26% 잘림)로 확인됐다. 1.34 × 1.78 ≈ 2.39 로 앞의 추론과 맞는다. 이 한 쌍이 적용 전후 스크린샷 후보다.
- 캡처는 개발자 도구로 1280×800 페이지 영역만 찍는다. 작업 표시줄, 탭 막대, 추천 영상 썸네일(남의 저작물)이 들어가지 않게 한다.
- 결정할 것: 어떤 장면을 몇 장 찍을지, 캡처에 쓸 영상, 타일을 누가 만들지.
- 출처: 웹 조사 4.2.1, 4.2.2 (2026-09-30)

## Q11. Alt+P 가 macOS 에서 π 입력을 가로챔

0.5.0 에서 PIP 키를 `Alt+P` 로 뒀다. macOS 에서는 Option+P 가 π 를 찍는 조합이다. 코드리뷰 M5 와 같은 종류다. 전 세계에 내기로 했으므로(Q2) 출시 전에 정해야 한다.

- 선택지: 그대로 두기(입력칸에서는 이미 무시한다), macOS 에서만 다른 키 쓰기, 키를 바꾸기.

## Q12. 스토어의 '단일 목적' 설명

기능이 채움, 회전, PIP, 창 채움, 프레임 넘기기로 늘었다. 스토어는 확장이 좁은 한 가지 목적을 갖도록 요구한다. "유튜브 재생기의 화면을 보는 방식을 조절한다" 로 묶어 설명할 수 있는지 스토어 글을 쓸 때 확인한다.
